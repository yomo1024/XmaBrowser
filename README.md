# XMA Browser

在游戏里逛 **XIVModArchive**：搜索、浏览、**点一下就装进 Penumbra 并即时生效**，不用切出游戏。

## 安装

Dalamud → 设置 → 实验性 → **自定义插件源**，粘贴：

```
https://raw.githubusercontent.com/yomo1024/XmaBrowser/main/pluginmaster.json
```

主地址不通时用备选（下载走 jsdelivr，国内多数网络更快）：

```
https://cdn.jsdelivr.net/gh/yomo1024/XmaBrowser@main/pluginmaster-cdn.json
```

然后在插件列表里搜 **XMA Browser** 安装即可。

> **加了源却看不到插件 = 清单没取到**（不是安装失败）。用那台机器的浏览器打开上面的地址：
> 能看到 JSON 文本 = 网络没问题（换个源重试）；打不开 = 网络到不了，改用下面的本地安装。

<details>
<summary>本地安装（开发用）</summary>

把 `bin/Release/` 整个目录拷到 `%APPDATA%\XIVLauncher\devPlugins\XmaBrowser\`
（区域版启动器是 `XIVLauncherCN`），然后 `/xlplugins` → Dev Plugins → 启用 **XMA Browser**。
</details>

## 功能

- **搜索 / 浏览** —— 关键词默认**按标题精确搜**（粘一个 Mod 全名就能找到它；想连描述一起搜，
  高级搜索里打开「关键词按全文搜」）+ 高级搜索（名称 / 作者 / 标签 / 种族 / 性别 / 类型 / 影响替换）；
  列表与宫格两种视图；滚到底自动加载下一页。
- **7 种排序** —— 最新发布 / 最近更新 / 下载最多 / 浏览最多 / 今日最多浏览 / 名称 / 相关度。
- **一键安装** —— 下载 → 解析包 → 装进 Penumbra → 启用 → 重绘，立刻可见。
  支持 `zip / 7z / rar / tar / pmp / ttmp2`，包里有多个 Mod 会逐个装。
- **装前看包** —— 不下载整包，几秒内看清**真实大小**、包里是什么、**会装进去几个 Mod**，
  并**勾选只装其中某几个**（约 0.25 MB 流量；48 MB 的包实测 4 秒）。
  `.7z/.rar` 列不出内容时会如实说明。
- **自动归组** —— 按模板把 Mod 放进文件夹，在 Penumbra 里就是可折叠的组（默认 `XMA/{类型}`）。
- **封面** —— 随包一起交付，并在 Penumbra 的 mod 面板里绘制出来。
- **NSFW** —— 走本机浏览器通道，插件内可直接登录，不用借用你日常浏览器的登录态。
- **翻译** —— 标题与描述可翻中文（谷歌 / 有道 / 腾讯 / OpenAI 可选）。
- **收藏** + **关注作者**，「只看新品」。
- 安装队列（进度 / 取消 / 失败重试）、缓存占用与一键清理、界面缩放、诊断日志。

命令：`/xma` 打开窗口。

## 已知限制

- **外链 Mod 不能一键装** —— 作者把文件放在 Patreon 等外部站点时没有直链，插件只提供
  「用默认浏览器打开」和「复制链接」，下载与安装仍需你自己来。
- **NSFW 需要你在本机浏览器登录过 XMA**（插件内可直接登录）。没登录过自然取不到，插件会明确告诉你。
- **站点改版可能让解析失效** —— 解析层带真实 HTML 样本的回归测试，改版时先看哪条断言挂了。
- 站点每页固定 15 条。

## 排查问题

「关于」页底部有**诊断日志**（最近 80 条），旁边可一键复制，直接贴给开发者即可；
也可以 `/xllog` 打开 Dalamud 日志窗口。

## 隐私与许可

只**读**站点公开数据；浏览器通道复制的是**你本机浏览器自己的** cookie，**不上传、不写日志**，临时 profile 用完即删；全流程不回传任何数据到第三方。
