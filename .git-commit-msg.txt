feat(ui): v0.2.0 —— 分页签界面 + 高级搜索 + Penumbra 封面

按主人游戏内反馈重做：

界面
- 主窗口改分页签：浏览 / 队列 / 设置 / 关于（后续功能有地方放）
- 重排布局与列宽：搜索行与过滤行分开，不再挤在一行；结果表加表头冻结、
  缩略图列、列宽固定/拉伸分明；顶部状态行显示 Penumbra 与通道状态
- 设置从主窗口里挪进「设置」页签，按功能分块

搜索
- 新增「高级搜索」弹窗：名称 / 作者 / 标签 / 种族 / 性别 / 类型 id / 影响替换
  + 排序 / 仅当前版本兼容 / NSFW；留空即不看该条件
- 支持把关键词当标签精确检索；主界面显示当前生效的筛选条件

封面（新增 Cover 模块）
- CoverLocator：在 mod 目录里找可绘制的封面（只认 png/jpg/jpeg ——
  Dalamud 的贴图加载不认 WebP）；识别真 WebP（RIFF....WEBP）避免
  「jpg 改名成 cover.webp」的假货把后续修复 skip 死锁
- CoverInjector：把封面塞进包再交给 Penumbra（包内没图 = 装出来没图），
  同时写 cover.<ext> + images/_MetaImage.<ext> + meta.json 的 Image；
  装完后还有一次目录兜底；已有真 WebP 封面则不覆盖
- PenumbraCoverDrawer：挂 PreSettingsTabBarDraw 在 Penumbra 的 mod 面板里画封面
  （与 Heliosphere 同机制），封面高度可调
- CoverFetcher：优先直连取图，被拒则走浏览器通道（浏览器 canvas 转 JPEG 回传，
  顺带解决 WebP 在 Dalamud 里显示不了的问题）

健壮性
- 站点对直连做 Cloudflare 挑战（Just a moment）时，搜索/详情自动降级到浏览器通道
- 浏览器通道新增 GetImageBytesAsync（取图并转 JPEG）

自测：编译 0 警告 0 错误；无游戏自测 68/68（新增 15 条封面断言：
定位优先级、真伪 WebP 判定、注入包后条目与原文件完整性、meta.json 改写）
